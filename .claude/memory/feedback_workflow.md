작업 사이즈와 무관하게 **CE 메타-루프** 형태를 유지합니다: Strategy → Plan → Build → Review → Reflect.

- 한 줄 수정도 종료 시 `/ce-compound`로 학습 1줄 기록
- `/execute-plan` 또는 `/ce-work` 시작 전 항상 plan 산출물 필수 (구두 합의 ❌)
- "그냥 빨리"는 다음 작업을 더 어렵게 만든다 — CE 철학과 정면 충돌

**Why:** 사용자가 명시적으로 "Compound Engineering 철학을 녹여서" 셋업을 요청. CE 핵심 명제는 "각 작업 단위가 다음 단위를 쉽게 만들어야 한다"이며, Reflect 단계 생략은 이 명제를 깨뜨림.

**How to apply:** 작업 종료 시 다음 중 하나라도 수행 — `/ce-compound`(학습 codify), `/retro`(회고), 또는 메모리 파일에 1-3줄 직접 추가. 빠르고 가벼워도 OK, 누적이 핵심.
